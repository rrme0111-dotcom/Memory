## 产品目标

本产品整合三个方向，通过"一个App、一条时间轴、三种记忆漩涡类型"的架构，为用户提供跨场景的情感记忆管理能力。以下三个目标相互正交，分别对应不同维度的成功定义：

### 目标一：建立私密情感记忆的极简记录工具（工具价值）
**目标描述：** 让用户在3步内完成一条"媒体+感受+自定义时间戳"的情感记忆，将碎片化的情绪瞬间结构化为可回看的一生记忆博物馆。

**衡量方式：**
- 首次记录完成率 ≥ 50%
- 单条记忆创建平均耗时 ≤ 30秒
- 自定义时间戳使用率 ≥ 40%

### 目标二：构建双人/家庭共建的关系记忆连接（社交价值）
**目标描述：** 通过一条共建时间线，让异地伴侣、家庭成员共同贡献记忆，以声音、照片、留言实现"不在身边也能感受陪伴"。

**衡量方式：**
- 双人绑定率 ≥ 35%
- 周活跃共建记忆数（北极星指标）持续环比增长
- 情侣向7日内邀请伙伴成功率 ≥ 60%

### 目标三：将纪念日与成长里程碑从"淹没"中拣选出来（仪式价值）
**目标描述：** 通过智能识别和主动推送，让用户生活中的"第一次"和高光时刻不被数千张照片淹没，转化为可仪式化的纪念日和成长节点。

**衡量方式：**
- 纪念日标记率 ≥ 60%
- 30日内首个纪念日触发率 ≥ 50%
- 成长里程碑自动归类准确率 ≥ 80%

## 用户故事

### US-1｜异地伴侣共建记忆线（P2方向，高付费意愿）
> **作为异地伴侣，我想和另一半共建同一条记忆线并互相留言，以便即使不在一起也能感受彼此的日常陪伴与情绪连接。**

- **主角：** 陈昊&苏苏，异地恋爱2年
- **场景：** 陈昊在上海出差，拍了张外滩夜景照片，录了一段30秒语音"今天路过外滩，想如果你在旁边就好了"，自定义时间戳为"今晚20:15"。苏苏收到推送，在同一条记忆线上回复语音"下次我们一起来"。两人看到这条记忆并排出现"陈昊视角"和"苏苏视角"。
- **验收要点：** 共建时间线、语音留言、双人视角并排、实时推送通知

### US-2｜独居者私密情感博物馆（P0方向，核心人群）
> **作为注重情绪健康的独居者，我想在私密空间为每张照片配上感受和自定义时间戳，以便多年后回看还原的不只是事件，还有那一刻的我。**

- **主角：** 林薇，28岁，互联网产品运营，单身独居
- **场景：** 周日下午，林薇翻到一张三个月前拍的雨天窗台照片，补录一条记忆：选照片→写感受"那天特别孤独，但雨声让我平静"→自定义时间戳设为3个月前→添加情绪标签"孤独·平静"。
- **验收要点：** 自定义时间戳精确到分钟、情绪标签、端到端加密隐私保护、补录场景3步完成

### US-3｜新手妈妈管理宝宝和宠物成长（P1方向，家庭向）
> **作为新手妈妈，我想为宝宝和宠物各建独立成长时间轴并标记里程碑，以便那些"第一次"不在数千张照片里被遗忘。**

- **主角：** 王悦，32岁全职妈妈，1岁宝宝+柯基犬
- **场景：** 宝宝第一次独立站立，王悦立刻拍视频→选"成长漩涡·宝宝"→标记为里程碑"第一次站立"→系统自动归入"12月龄"节点。
- **验收要点：** 多条独立成长时间轴、里程碑标记与自动归类、漩涡类型切换

### US-4｜普通日子升格为纪念日（跨方向，仪式感）
> **作为情侣/个人，我想把某普通日子标记为纪念日并收到提醒，以便生活的高光被主动拣选与仪式化。**

### US-5｜补录场景：手动设定记忆时间（跨方向，留存命脉）
> **作为常事后补录的人，我想添加记忆时手动设定记忆时间而非采用拍摄时间，以便记忆时间线与我内心的故事线一致。**

### 用户旅程关键触点

1. 首次打开→按身份选场景（情侣/个人/家庭宠物）
2. Onboarding→30秒内完成第一条记忆（照片+感受+时间戳）
3. 邀请伙伴（情侣向）→一键邀请共建
4. 标记首个纪念日→触发仪式感
5. 回看记忆→7天后推送"一周前的今天"

**留存拐点：** 首日完成1条记忆(D1) + 情侣向7天内邀请伙伴(W1) + 首个纪念日触发(30天内)

> **关键洞察：MVP的生死线是「补录场景」——"自定义时间戳+语音留言+3步创建"是留存命脉。**

### 差异化策略

| # | 策略 | 竞品空白 |
|---|------|---------|
| D1 | 自定义时间戳：回填任意时间点+模糊时间戳+多层感受叠加 | 全行业空白 |
| D2 | 照片+感受深度绑定：长按录音+情绪标签+感受滤镜 | 普遍缺失 |
| D3 | 纪念日升级为记忆回顾：自动拼接+时光对比 | Day One部分覆盖 |
| D4 | 双人共建关系记忆线：共建时间线+双人视角并排 | 恋爱记/Between部分覆盖 |
| D5 | 三能力合一：一条时间轴承载三类记忆 | 无竞品覆盖 |

### 护城河
1. 三能力合一的数据架构——竞品跨品类整合需推翻重来
2. 自定义时间戳+记忆层叠加是结构性创新
3. 情感化定位 vs 工具化/社交化定位，占据不同用户心智

## 关键流程图

### 核心流程：创建记忆→添加感受→自定义时间戳→标记纪念日→双人共建→时间轴回看

```
用户打开App
    │
    ├── 首次使用？──是──→ [流程A] Onboarding: 选场景(情侣/个人/家庭)
    │                                   ↓
    └── 否 ──────────────────────→ 进入时间轴
                                           │
                                           ↓
                    [流程B] 创建记忆
                    Step 1: 选媒体（照片/视频，最多9个）
                    Step 2: 写感受（文字+语音，60s）
                    Step 3: 设时间戳
                      ├─ 默认：当前时间
                      ├─ 精确时间：自定义年月日时分
                      └─ 模糊时间：去年夏天/某天晚上（Pro）
                    [可选] 添加情绪标签
                    [可选] 长按照片录制独立语音感受
                                           │
                                           ↓
                    [流程C] 标记纪念日（可选）
                    ├─ 是 → 命名纪念日 + 设提醒
                    └─ 否 → 跳过
                                           │
                                           ↓
                    [流程D] 双人共建（情侣向）
                    ├─ 已有共建 → 自动同步至伙伴 + 推送
                    └─ 首次共建 → 发起邀请（链接/二维码/邀请码）
                                           │
                                           ↓
                    [流程E] 时间轴回看
                    ├─ 按时间倒序/正序浏览
                    ├─ 按漩涡类型/情绪标签筛选
                    ├─ 7天后推送"一周前的今天"
                    └─ 往年同日"那年今日"回顾
```

### 补录场景流程（MVP生死线）

```
用户拍了照片（3天前）→ 打开App → 创建记忆 → 选照片
→ 写感受（文字/语音）→ 点击时间戳字段
  ├─ 精确时间 → 调整为3天前20:15 → 记忆排入正确位置 ✓
  └─ 模糊时间 → "前几天的一个晚上"（Pro）→ 排入近期模糊区间 ✓
```

## Non-goals（明确不做什么）

| 编号 | 不做 | 原因 |
|------|------|------|
| NG-1 | 社交社区/信息流 | 私密情感工具，社交化稀释隐私心智 |

| NG-6 | AI生成内容（v1） | 聚焦核心记录体验，AI生成降低真实情感投入 |
| NG-7 | Android（v1仅iOS） | MVP资源聚焦，iOS付费意愿更高 |
| NG-8 | Web端 | 情感记忆是移动场景 |
