## 设计规格

### 视觉风格
- **风格**：灰阶框线图
- **主色**：`#333333`（描边）
- **选中态**：`#E8E8E8`（浅灰填充）
- **辅助色**：`#8A8A8A`（辅助文字）
- **强调色**：`#4A90D9`（交互标注/链接）
- **锁定态**：`#CCCCCC`（灰显+🔒标记）

### 字体
- 中文：系统字体（PingFang SC / Sarasa Gothic SC）
- 英文/数字：Inter / SF Pro

### 组件规范
- **状态栏**：375×44px，时间居左，信号/WiFi/电量居右
- **导航栏**：375×44px，标题居中，返回/操作居左右
- **TabBar**：375×83px，4-5个Tab项，选中态高亮
- **场景卡片**：圆角12px，边框1px #333，内边距16px
- **时间轴卡片**：圆角8px，左侧时间标记，右侧内容
- **浮动按钮(+)**：直径56px，圆形，右下角，边框1px #333

### 渐进解锁视觉
- **已解锁**：正常灰阶描边 + 图标
- **未解锁**：`#CCCCCC` 灰显 + 🔒图标 + "创建共建空间后解锁"提示文字

### 多视角折叠/展开
- **折叠态**：显示首条记忆 + "N条多视角记录"灰色提示条 → 点击展开
- **展开态**：并排卡片，最多2列，每列含记录者头像+感受文本

### 场景徽标配色
| 场景 | 徽标色 | 图标 |
|------|--------|------|
| 个人 | `#7B8FA1`（蓝灰） | 独处剪影 |
| 情侣 | `#D4737A`（粉红） | 双人 |
| 友情 | `#5B9B7D`（绿） | 多人 |
| 成长 | `#C4A45D`（金棕） | 人物轮廓 |

## 交互标注

框线图内包含蓝色虚线箭头标注核心用户旅程：

1. S01→S02：Onboarding 场景选择 → 引导
2. S02→S03：引导完成 → 进入个人中心聚合视图
3. S03→S04：点击"+" → 场景选择器弹出
4. S04→S05：选择场景 → 进入记忆创建
5. S05→S06：选媒体+写感受 → 设置时间戳
6. S06→S03：保存 → 返回聚合视图
7. S03→S10：切换到共建Tab → 邀请伙伴
8. S10→S11：邀请完成 → 共建时间线
9. S03→S13：切换到成长Tab → 主体选择
10. S13→S14：选择主体 → 成长时间轴
11. S03→S12：点击"全部记忆" → 全场景时间轴
12. S07→S08：记忆详情 → 标记纪念日

## 与v1.0的关键差异

| 差异 | v1.0 | v2.0 |
|------|------|------|
| 场景数 | 3（个人/双人/家庭） | 4（个人/情侣/友情/成长） |
| 场景选择 | 首次Onboarding选一次 | Onboarding + 每次新建记忆时选(场景选择器) |
| 成长场景 | 含共建 | 独立追踪，无共建 |
| 共建系统 | 仅情侣 | 情侣+友情共用 |
| 个人中心 | 单一时间轴 | 分场景Tab + 全场景聚合(双视图) |
| 多视角 | 无 | 折叠/展开并排 |
| 渐进解锁 | 无 | 友情/成长逐步解锁 |
